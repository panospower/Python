# Python

A small collection of Python experiments focused on mathematics, probability, and learning programming.

## Scripts

| File | Description |
| --- | --- |
| [`approx.py`](approx.py) | An interactive menu for mathematical approximations.Added Pi(π) Euler's number (e) and the golden ratio(φ).All accompanied with their own calculation methods. Work in progress |
| [`biology.py`](biology.py) | Simulates repeated random selections across a user-defined number of categories. It prints the counts and percentages, compares the results with the expected uniform percentage, and calculates a simple deviation-based accuracy score. |
| [`shi.py`](shi.py) | Contains experimental functions for estimating **e** with a Taylor series and counting the digits in a hard-coded decimal number. The functions are defined but are not called automatically when the file runs. |

## Requirements

- Python 3
- No third-party packages are required; the scripts use Python's standard library.

## Run a script

Clone the repository:

```bash
git clone https://github.com/panospower/Python.git
cd Python
```

Run a script with Python:

```bash
python approx.py
python biology.py
python shi.py
```

On some systems, use `python3` instead of `python`.

### Notes

- `approx.py` Current main project on approximating a number of mathematical constants..
- `biology.py` asks for the number of categories and the number of random attempts. Use positive integers for both inputs.
- `shi.py` currently only defines its functions, so running the file by itself does not print a result.
